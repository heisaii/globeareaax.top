# GlobeAreaAX static site

Static mirror of the former WordPress site, prepared for GitHub Pages at `https://globeareaax.top/`.

The deployable website is in `site/`. Pushing the `main` branch runs the GitHub Pages workflow automatically.

## Domain setup

- GitHub Pages custom domain: `globeareaax.top`
- Apex DNS records: GitHub Pages A/AAAA records, or the DNS values shown by GitHub
- Optional `www` record: CNAME to the repository owner's GitHub Pages hostname

Keep the old domain online with matching page-by-page redirects if search ranking preservation is required.
